# Hi, I'm Nicolas 👋

I build software focused on **determinism, privacy, and system frugality**. 

I favor local-first execution, strict architectural boundaries, and pragmatic code over bloated toolchains and probabilistic over-engineering.

---

### 🛡️ Core Engineering Values

* **Determinism First:** If a task can be solved with a predictable script, never waste compute on a LLM.
* **Privacy & Local Execution:** Data belongs to the user. My tools prioritize local runtimes (Docker, local models, native scripts).
* **Frugality & Zero Pollution:** Minimal dependencies, ephemeral containers, and low cognitive overhead.
* **Robustness:** Built for real-world reliability and long-term maintainability.
